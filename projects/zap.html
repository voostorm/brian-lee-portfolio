Games & graphics / Personal project

Zap

A minimalist survival shooter: dodge incoming squares, fire in eight directions, and try again.

  • Python
  • Pygame
  • Game loop
  • Collision detection

Solo · AI-assisted development

01 / The problem

What this project explores

I wanted to turn a simple survival-game idea into a complete interactive loop while learning game programming.

02 / My contribution

The work I took on

Designed and built a Pygame shooter with generative-AI assistance, covering movement, projectiles, enemy spawning, and the restart flow.

  • Implemented the start-screen, gameplay, game-over, and retry states.
  • Added procedural enemy spawning with speed and spawn-rate changes over time.
  • Included projectile and enemy updates, collision detection, and a survival timer.

03 / The result

What it demonstrates

A small locally runnable Python game with a recorded demo. The repository includes installation instructions; there is no hosted playable build.
