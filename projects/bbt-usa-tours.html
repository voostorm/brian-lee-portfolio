Backend & web / Live website

BBT USA Tours

A bilingual travel-services website that helps visitors explore private tours and airport transfers, then request a tailored quote.

  • React
  • Tailwind CSS
  • React Router
  • i18next

Solo development · Business website

01 / The problem

What this project explores

Travelers need to understand destinations, service options, and trip requirements before contacting a private tour operator. BBT USA serves both English- and Korean-speaking customers.

02 / My contribution

The work I took on

I developed the website independently, bringing service discovery, destination information, bilingual content, and quote requests into one customer-facing experience.

  • Built responsive layouts for browsing airport transfers, day tours, multi-day trips, and specialty travel services.
  • Organized destination and transfer pages with itinerary information, service details, pricing, and frequently asked questions.
  • Provided English/Korean language switching using i18next, with React Router navigation between service pages.
  • Integrated a quote-request form with required fields, trip dates, pickup and drop-off locations, passenger and luggage counts, and submission feedback through a hosted form service.

03 / The result

What it demonstrates

A publicly accessible business website that connects service browsing to a structured travel inquiry. Visitors can explore the live site and request a custom quote.
