Library Database Application

A relational library system for books, members, loans, returns, and overdue payments.

  • Java
  • JDBC
  • MySQL
  • SQL

Individual coursework · Tennessee Tech

01 / The problem

What this project explores

Library records connect many entities: books and authors, physical copies, members, loans, and payments.

02 / My contribution

The work I took on

Completed a multipart database project and built a Java command-line application that queries and updates a MySQL library database through JDBC.

  • Implemented menu-driven workflows for borrowing, returning, and renewing book copies.
  • Used prepared statements and SQL joins to retrieve related records and member loan details.
  • Included queries and updates for overdue balances and payment registration.

03 / The result

What it demonstrates

Practice translating relational data into usable application workflows, with SQL and Java application code available for review.
