Fish Fish

A fishing-combat roguelike with a cast, hook, and reel loop—and playtest telemetry.

  • Unity
  • C#
  • WebGL
  • Firebase

6-person team · 2 months · USC

01 / The problem

What this project explores

Our team explored how fishing could become an active combat mechanic, with dodging, timing, and room-to-room progression.

02 / My contribution

The work I took on

Contributed to the fishing-rod combat loop, enemy behaviors, progression systems, and playtest event logging in a six-person Unity project.

  • The game combines charged casting, hook detection, and reeling with distinct enemy movement and attack patterns.
  • Runs connect ocean rooms with coins and shop upgrades for range, reel speed, and survivability.
  • The project includes UnityWebRequest-based logging to Firebase and a Google Apps Script / Google Sheets endpoint for playtest analysis.

03 / The result

What it demonstrates

A playable Unity WebGL team project. The public copy provides project code; the original course repository and detailed team commit history are private.
