Coursework · USC CSCI 522

01 / The problem

What this project explores

An interactive 3D scene depends on coordinated rendering, movement, animation, and behavior systems.

02 / My contribution

The work I took on

Implemented engine and gameplay milestones in the course-provided PrimeEngine, integrating C++ logic with Lua hooks and Maya-exported assets.

  • Added AABB bounding volumes and plane-based frustum rejection, with a focused scene and debug visualization for checking culling.
  • Implemented gravity and collision response for character and environment interaction.
  • Worked on full-body, partial-body, and additive animation blending, plus waypoint patrol and aim-at behavior transitions.

03 / The result

What it demonstrates

Experience extending an existing C++ engine across several interacting subsystems. The public repository contains a written milestone outline, rather than engine source or an executable demo.
