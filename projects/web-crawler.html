Concurrent Web Crawler

A multithreaded crawler and search-evaluation workflow that turn web pages into inspectable data.

  • Python
  • Threads & queues
  • Beautiful Soup
  • CSV / JSON

Individual coursework · USC

01 / The problem

What this project explores

Collecting web pages requires controlling traversal, handling unreliable requests, and recording what was actually fetched.

02 / My contribution

The work I took on

Implemented a Python crawler with a shared URL queue, worker threads, depth and domain checks, request timeouts, and CSV reports. In a related assignment, I compared search results across 100 queries.

  • Configured seven worker threads and used locks around shared counters and output operations.
  • Recorded fetch status, content type, file size, and outgoing links, with separate reports for encountered and visited URLs.
  • The companion evaluation script exports search results as JSON and computes overlap and rank-correlation statistics in CSV.

03 / The result

What it demonstrates

Inspectable collection and evaluation artifacts, with practical experience in concurrency, HTTP failure handling, parsing, and data reporting.
