01 / The problem

What this project explores

In a fast arena match, inconsistent icon order or incorrect cooldown visibility makes game state harder to read.

02 / My contribution

The work I took on

Maintain personal modifications to existing World of Warcraft addons, including OmniCD, GladiusEx, and NameplateCooldowns. I define the behavior I need, investigate problems, and iterate on fixes with AI assistance.

  • Added saved drag ordering and test-mode configuration so cooldown layouts can be prepared ahead of play.
  • Worked on specialization, talent, and party-composition conditions that control cooldown visibility and ordering.
  • Adjusted cooldown baselines and repaired configuration and display behavior across multiple addons.

03 / The result

What it demonstrates

An ongoing maintenance project driven by actual use: translating UI problems into event, state, and configuration changes. Original addon authors retain credit for the underlying projects.
