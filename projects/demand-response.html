Demand Response Portal

An energy-data web platform, with backend APIs for managing organizations, users, and meters.

  • Python
  • Flask

Team capstone · Tennessee Tech

01 / The problem

What this project explores

Power consumers and providers need a way to organize meter data and explore energy usage. Our capstone team built a web portal for those workflows.

02 / My contribution

The work I took on

My primary responsibility was the backend API for the administrator and organization pages. I worked on operations that add, update, and retrieve the records those pages display.

  • Seven route handlers across the administrator and organization API modules cover organization lists, member updates, meter assignment, and creation operations.
  • Used SQL queries and joins to retrieve organization members, update records, and return JSON responses to the frontend.
  • Worked in an Agile team over roughly six months. The shared application includes Flask, MariaDB, Redis, Nginx, and Docker Compose.

03 / The result

What it demonstrates

A team-built capstone connecting web interfaces, API behavior, and relational data. The linked modules show my main area of contribution.
