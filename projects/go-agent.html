Data & AI / Fall 2024

Adversarial Go Agent

A small-board Go agent that weighs candidate moves under a search-time budget.

  • Python
  • Alpha-beta search
  • Heuristics
  • Iterative deepening

Individual coursework · USC

01 / The problem

What this project explores

A turn-based game agent must choose useful moves while balancing search depth against limited decision time.

02 / My contribution

The work I took on

Implemented a Go-playing agent with iterative deepening, alpha-beta search, opening moves, and a position-evaluation function.

  • Evaluated positions using stone counts and liberties, and explored candidate legal moves.
  • Set a maximum search depth and a time limit, with checks during move selection.
  • Included fallback behavior for a legal move or pass when the search does not produce a move.

03 / The result

What it demonstrates

A focused implementation of adversarial search and heuristic decision-making. Running it requires the assignment’s game harness.
