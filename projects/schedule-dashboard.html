Academic Schedule Dashboard

Java services that turn course schedules into filtered results and credit-hour summaries.

  • Java
  • Spring Boot
  • Maven
  • JUnit

Individual coursework · Tennessee Tech

01 / The problem

What this project explores

Raw course data needs to be organized by subject, faculty, section, and term before it is useful in an academic dashboard.

02 / My contribution

The work I took on

Built backend service methods across three coursework iterations, consuming a schedule service and exposing query results through Spring Boot GET endpoints.

  • The final ServiceBridge defines 13 GET mappings, including course, faculty, subject, and term-based queries.
  • Returned domain objects and Java collections such as SemesterSchedule, CourseInstance, and ArrayList for different query shapes.
  • Included seven JUnit tests in the final iteration for multi-term, faculty, subject, and course lookup behavior.

03 / The result

What it demonstrates

A concrete example of object-oriented modeling, service integration, API design, and testing. The coursework depends on its original schedule service.
